# Hero & equipment images

Drop these files in this folder — the Dashboard's hero banner picks them up
automatically (no code changes, no rebuild needed, just refresh the browser).
Until a file exists, the UI falls back to the built-in vector icon /
gradient background, so nothing breaks in the meantime.

| Filename | What it is | Suggested size |
|---|---|---|
| `hero-bg.jpg` | Illustrated skyline background (hospital / data center / industrial) | ~1600×700px landscape |
| `equip-plc.png` | PLC / control panel photo | Square-ish, transparent or white background |
| `equip-generator.png` | Generator set photo | Square-ish, transparent or white background |
| `equip-ats.png` | ATS cabinet photo | Square-ish, transparent or white background |
| `equip-meter.png` | Power meter photo | Square-ish, transparent or white background |
